# 🇬🇧 Guia de Londres — Site Institucional e Turístico

Este projeto consiste no desenvolvimento de uma aplicação web responsiva dedicada a apresentar a história, a cultura, os pontos turísticos e curiosidades sobre a cidade de Londres. O objetivo principal é consolidar conhecimentos fundamentais de desenvolvimento Front-End, aplicando uma identidade visual inspirada na paleta de cores da bandeira britânica e estruturação semântica limpa.

## 📱 Status do Projeto
